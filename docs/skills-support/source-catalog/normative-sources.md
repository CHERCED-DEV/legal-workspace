## Regla de verificación

El Diario Oficial es la referencia primaria para promulgación/publicación. SUIN-Juriscol y Función Pública son fuentes institucionales útiles para localizar y leer textos integrados, pero sus avisos informan que no certifican por sí solos la vigencia. Cuando un efecto jurídico sea material, conservar Diario Oficial, texto/pasaje, fecha relevante, reformas, transición y jurisprudencia aplicable. Estado crítico: **`CROSS_CHECK_REQUIRED` (se requiere contraste adicional)**.

## Mapas de relación prioritarios

- Información pública: N-L1712 + N-D103/N-D1081, con tensión concreta frente a N-L1581 y reserva profesional.
- Documento digital: N-L527 + reglamentación + N-L2213 + regla procesal especial + evidencia concreta y procedencia.
- Familia/protección: N-L1098 + N-L2126 + N-L294 + N-L1257; N-L1996 solo aplica a personas mayores de edad con discapacidad.
- Laboral: N-CST y reformas sustantivas, incluida N-L2466; N-L2452 regula el procedimiento y no reemplaza el análisis sustantivo.
