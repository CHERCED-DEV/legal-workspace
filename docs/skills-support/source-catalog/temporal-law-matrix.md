## Nota obligatoria para el caso laboral A/B

Para el diseño de Skills, la Ley 2452 es la prueba de calidad temporal: el análisis debe pedir la fecha de inicio/presentación del proceso y revisar el art. 330. El resultado no puede ser el mismo para casos temporalmente distintos solo porque la norma nueva esté vigente a la fecha de consulta. La orientación de [MinJusticia](https://www.minjusticia.gov.co/programas-co/LegalApp/Paginas/%C2%BFQu%C3%A9-Ley-se-aplica-a-mi-demanda-laboral-si-la-present%C3%A9-despu%C3%A9s-del-2-de-abril-de-2026-.aspx) es `VERIFIED_SECONDARY`/institucional: ayuda a formular la pregunta, no reemplaza texto ni interpretación judicial en un caso límite.
