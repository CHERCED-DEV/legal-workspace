# Patrones de redacción — Tipos de documento no son Skills

## Regla de composición

Un nombre de documento normalmente especifica *para qué* se redacta, no *cómo* razona el modelo. El patrón seguro es:

```text
contexto del Case + fact/evidence work + investigación/Knowledge Pack + legal-drafting
+ revisión + decisión humana + template opcional
```

## Mapa inicial

| Documento/actuación | Capacidades compuestas | Reglas que no vive en Skill | Template posible |
|---|---|---|---|
| Demanda | intake, fact/evidence, research, drafting, review | competencia, requisitos, cuantía, procedibilidad, canal/fecha | estilo de firma/oficina |
| Contestación | evidence, contradiction, research, drafting/review, adversarial | efectos de silencio, excepciones, carga, términos | estructura de respuesta |
| Memorial | contexto, intención procesal, drafting/review | procedencia, destinatario, canal, anexos | tipo de memorial |
| Derecho de petición | extraction, research, drafting/review | modalidad, término, deber de respuesta | formato de oficina |
| Recurso | análisis de providencia, research, drafting/review | disponibilidad, legitimación, término, efecto | estructura de agravios |
| Concepto | issue-spotting, research, drafting, review | derecho aplicable y recomendación profesional | portada/tono |
| Providencia/proyecto | facts/evidence, research, adversarial, drafting/review | competencia, valoración, determinación y firma | estructura institucional |

## Patrón de borrador seguro

1. Nombrar destinatario, producto, rol, jurisdicción y fecha relevante como inputs.
2. Separar hechos, fuentes, supuestos, argumentos y decisiones pendientes.
3. Escribir secciones a partir de workflow/Knowledge Pack, no de un template ciego.
4. Marcar toda afirmación factual sin Evidence y toda autoridad sin fuente/fecha/estado.
5. Ejecutar revisión formal/semántica y entregar a la humana con una lista de decisiones.

## Patrón de salida

Nunca usar “listo para firmar/radicar” como estado de una Skill. Usar: `borrador para revisión`, `información faltante`, `fuente por verificar`, `decisión profesional requerida` y `riesgo de procedimiento por confirmar`.
