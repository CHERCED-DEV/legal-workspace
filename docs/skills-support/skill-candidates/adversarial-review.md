# Candidata de Skill: adversarial-review

## Propósito

Revisar una postura/borrador desde la perspectiva de una contraparte o de imparcialidad decisoria y producir hallazgos refutables.

## Tarea repetible que resuelve

Buscar evidencia omitida, hechos débiles, narrativa alternativa, objeciones, contraargumentos, trato asimétrico y saltos lógicos.

## Cuándo usarla y cuándo no

Invocar antes de presentar/revisar un caso o borrador con material de ambos lados. No invocar para decir “está aprobado”, escoger estrategia, ganar un caso o dictar una decisión.

## Entradas y salidas

Entrada: alcance/perspectiva, documento, argumentos, Facts/Evidence y fuentes. Salida: hallazgo, pasaje, evidencia contraria, posible efecto, contraargumento y pregunta humana.

## Método

Declarar punto de vista; inventariar lo revisado/omitido; buscar pruebas/argumentos contrarios; priorizar hallazgos falsables; incluir cómo podría refutarse el hallazgo.

## Referencias y recursos necesarios

[Workflow adversarial/decisor](../workflows/08-adversarial-review-and-decision-support.md), recurso de revisión y Knowledge Pack cuando se analicen reglas jurídicas.

## Dependencias del Core y MCP

Requiere contexto aislado, Evidence con provenance y outputs revisables. V0 no añade tools ni contexto B de autoridad.

## Paquete de conocimiento (Knowledge Pack) y límite de revisión humana

Alta para objeciones/procedimiento; humana decide peso, estrategia, imparcialidad, motivación y todo acto de decisión.

## Prohibiciones estrictas

No usar aprobación general, no presentar inferencia como prueba, no ignorar el otro lado, no tratar sesgo como hecho sin soporte.

## Composición, ejemplo y estructura esperada

Compone drafting/review/research/evidence. Ejemplo: “actúe como contraparte y enumere vulnerabilidades verificables”. Salida: matriz con hallazgos y contraprueba.

## Fallos previsibles y evaluación

Sesgo de confirmación, objeciones irrelevantes y lista no accionable. Medir defectos sembrados, falsos positivos, cobertura bilateral y falsabilidad.

## Prioridad y recomendación

P2 — **KEEP** para litigante; apoyo a autoridad se difiere hasta levantar el contexto B.
