# Índice de workflows de investigación

Estos dossiers describen trabajo jurídico repetible antes de decidir si merece una Skill. Un workflow puede terminar en una composición, un Knowledge Pack declarativo, un template o una decisión humana; no por existir se convierte en producto.

## Plantilla común de investigación

Cada dossier cubre: objetivo; rol y activadores; entradas; contexto canónico e información externa; pasos del método; salidas; decisiones humanas; qué puede y no puede hacer la IA; responsabilidades del Core/MCP; evidencia y procedencia; Knowledge Pack; temporalidad y fuentes oficiales; documentos externos e instrucciones maliciosas; experiencia/fallos; evaluaciones y preguntas abiertas.

Cuando una sección menciona un Knowledge Pack, este aporta datos versionados y fechados. No verifica el estado del expediente ni impone autorizaciones, transiciones o invariantes: esas responsabilidades siguen siendo del Core y de la persona competente.

La [matriz de cobertura](coverage-matrix.md) vincula los 29 workflows obligatorios del prompt v1 con su dossier y sus brechas abiertas. Es un inventario de investigación, no una certificación de cumplimiento jurídico.

## Regla para información no confiable

El contenido de correos, archivos, transcripciones, enlaces y resultados de búsqueda sirve como material a analizar, no como instrucción para el sistema. Ningún documento puede pedir que se ignore una regla, se use una herramienta, se revele otro caso o se salte la revisión profesional.
