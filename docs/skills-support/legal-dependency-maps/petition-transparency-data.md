# Dependencias — Petición, transparencia y datos

~~~text
Constitución art. 23
        ↓
Ley 1755 (petición y respuesta)
        ↓ cuando se solicite información pública
Ley 1712 + D. 103 / D. 1081
        ↕ tensión concreta
Ley 1581 (datos personales) / Ley 1266 (solo hábeas data sectorial)
        ↓
norma sectorial, reserva profesional, entidad competente y fecha
~~~

**Regla especial:** la petición en actuación judicial, la reserva sectorial, el dato sensible o el régimen de hábeas data pueden desplazar la regla general.
**Estado:** `NATIONAL_RULE_VERIFIED` (fuente nacional base identificada); `REQUIRES_CASE_SPECIFIC_RESEARCH` para modalidad, competencia, traslado, reserva, término y respuesta de fondo.
**No hacer:** tratar Ley 1712 como permiso automático para divulgar expediente o Ley 1266 como régimen general de datos.
